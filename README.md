# SIKDER. — Video Editor & Thumbnail Designer Portfolio

A high-performance cinematic portfolio application for **Sikder Rakibul Islam** (Video Editor and High-CTR Thumbnail Designer), rewritten as a modern React SPA using Vite, TypeScript, and Tailwind CSS.

---

## ✨ Features & Architecture

- **React 19 & TypeScript**: Fully componentized modern architecture (`Header`, `Hero`, `Skills`, `Work`, `About`, `Contact`, `ProjectModal`, `AmbientSpotlight`).
- **Interactive Editing Timeline Workspace**: NLE-inspired multi-track timeline with live animated audio waveform bars, glowing timecode playhead, and keyframe blocks.
- **Interactive Software Mockups**: Realistic Adobe Premiere Pro / After Effects monitor workspace and Adobe Photoshop / Illustrator 16:9 thumbnail design artboard with active transform handles and layer inspectors.
- **Dynamic Portfolio Directory & Filter Engine**: Seamless tab filtering across "All projects", "Video edits", and "Thumbnails".
- **Cinema Theater & Artwork Modal**: Interactive modal with embedded responsive YouTube video playback and high-resolution thumbnail artwork inspection.
- **Ambient Cursor Spotlight**: Mouse-tracking radial gradient glow layer with reduced-motion respect.
- **Fast Build & Modern Tooling**: Built with Vite and Tailwind CSS.

---

## 🚀 Development & Build

```bash
# Install dependencies
npm install

# Start the dev server (runs on port 3000)
npm run dev

# Type check
npm run lint

# Production build
npm run build
```
